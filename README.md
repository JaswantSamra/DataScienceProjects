# Data Science Projects

A collection of self-contained data-science and machine-learning work —
exploratory analysis, modelling, data tooling, and small end-to-end
applications.

## Projects

- **[Stock Market Anomaly Detector](./Stock%20Market%20Anomaly%20Detector/)**
  — Desktop app that pulls historical equity data from multiple free
  providers (yfinance, Stooq) and flags statistically anomalous price
  events through two complementary rolling Z-score signals, with CSV
  export and a tabbed Tk interface.
